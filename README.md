# امین پوکر | Amin Poker

بازی چهار نفره Texas Hold'em برای اندروید؛ یک بازیکن انسانی در برابر سه رقیب هوش مصنوعی. بازی با ژتون مجازی انجام می‌شود و هیچ پرداخت یا پول واقعی ندارد.

## امکانات نسخه اولیه
- رابط فارسی و راست‌چین
- میز پوکر با ظاهر سه‌بعدی‌نما، کارت‌ها و ژتون‌ها
- چهار بازیکن و سه رقیب رایانه‌ای
- مراحل Pre-flop، Flop، Turn و River
- عملیات Fold، Check/Call و Raise
- محاسبه ترکیب‌های پوکر و تعیین برنده

## ساخت APK
پروژه را با Android Studio باز کنید و از مسیر Build > Build APK(s) خروجی بگیرید.
همچنین GitHub Actions با هر تغییر مرتبط، APK آزمایشی را می‌سازد و به‌عنوان Artifact منتشر می‌کند.

مسیر خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## نکته
این نسخه اولیه است. ظاهر میز با CSS سه‌بعدی‌نما پیاده‌سازی شده؛ مدل‌سازی سه‌بعدی کامل و انیمیشن‌های پیشرفته در مراحل بعدی قابل افزودن‌اند.
